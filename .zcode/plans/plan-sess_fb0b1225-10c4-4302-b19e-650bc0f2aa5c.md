## 三、4 页面 + 2 功能 实现要点

### 1. LoadingScreen
- fixed全屏，星芒A背景，2只简化CSS/SVG猫(占位，抠图轮替换为真实素材)+加载文字+进度条
- `simulateLoading()`：每200ms随机+15%，100%后停400ms再fade-out remove
- 加载文字轮换："正在准备温暖..."/"喵~ 马上就好..."

### 2. HeroSection（全屏多色块拼贴，文档§二）
- 6个色块(A左上文字块/B左侧白形/C中央主色块/D右上装饰/E右下按钮座/F底部波浪)，用CSS `border-radius`多值 + `clip-path`
- 中央主色块C：`warm-pink→peach→soft-coral`渐变 + `block-c-morph`呼吸动画
- Hero主角：**本轮用占位符容器**(标注"待抠图后放Leila+两猫组合")，z-index高于色块实现"超出边界"
- 左上粉色块内白字堆叠(PET DOCTOR / XXX'S SPACE / 中文治愈句)
- 右下按钮组(关于我/联系/更多)叠在色块E上，第一颗实心其余白底描边圆
- SVG粗涂鸦：右上蝴蝶结/空心菱石/粗手绘线/底部签名线
- 底部云朵名字标签(不规则border-radius + 胖圆字体)

### 3. AboutMe（紧凑不对称拼贴，文档§二页面二）
- 标题 `··· About Me ···` + 紫粉渐变进度条 + `2 of Me >`
- 左侧大图(占58%宽)用 `本人照片1.jpg`：白描边+粉外圈，左上圆点，右上SVG涂鸦线，左下白字"Hi~ I'm your pet doctor 🐾"
- **长按换图**：useLongPress hook(500ms触发) → FileReader读base64 → localStorage持久化 → 触摸/鼠标双端 + Vibration API + 视觉反馈(pressing类/进度环)
- 右侧4卡片纵列(信息卡/双图卡/彩色统计卡/Event卡)用半透明毛玻璃
- 目标高度≈1.2屏，绝对定位+负边距压缩

### 4. Gallery 照片墙（文档§三页面三）
- 深色墙板(默认黑板`#1a1a2e`，`border-radius:28px`，inset阴影凹陷感)
- PhotoWallManager类(utils/photoWall.js)：`MAX_PHOTOS=15`硬上限，满额拦截返回`{success:false,error:'FULL'}`
- 两种照片：拍立得(白边+底部日期) + 抠图(双层白描边轮廓)；初始填 本人照片(≤15张)
- 随机位置+碰撞检测：真随机坐标(非网格)，MIN_GAP=12，最多试30次，`photo-drop-in`弹性入场
- 随机属性：大小s/m/l/xl加权，旋转±10°，固定方式(pin/clip/tape)
- 点击放大Lightbox：全屏黑底，大图+左右导航+🗑️删除(二次confirm)+左右滑切
- 计数器`⑫/₁₅`，≥13红色闪烁警告
- localStorage持久化 key `my-photo-wall`

### 5. CreativeWorks 3D轮播收尾（文档§四页面四）
- `perspective:1200px; perspective-origin:50% 45%; transform-style:preserve-3d`
- 卡片状态：active(中间scale1)/prev(左translateX-75% rotateY25)/next(右)/prev2next2(更远blur)
- 轮播内容：本人照片(真实)，`cubic-bezier(0.23,1,0.32,1)`过渡
- 触摸滑动(50px阈值)+点击两侧卡片跳转+键盘←→(调试)+导航点
- isAnimating锁550ms防连击
- 收尾告别区：`✨ Thank you for visiting ✨` + 2只SVG简化猫挥手动画(wave-hand) + `Made with 💗`

### 6. PawProgress 🐾 进度条（文档功能一）
- 纯CSS脚印：1大圆(掌心)+4小圆(趾头用box-shadow画)
- 底部固定，4个脚印对应4 section
- 三态：未到达(淡灰轮廓opacity.3)/当前(实心肉粉+弹跳)/已浏览(深色)
- useScrollSpy检测当前section喂状态
